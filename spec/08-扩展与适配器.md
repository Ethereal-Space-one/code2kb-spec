# 扩展与适配器

适配器用于枚举特定技术栈的入口，扩展用于增加外部检查或项目特定敏感规则。

0.7 候选的[Adapter 输出契约](../docs/adapter-contract.md)先报告固定提交的文件和源码候选，再由复核者把它们归类到下述稳定入口模型。L1 文件盘点、L2 确定结构与 L3 关系能力分别声明；仅有词法匹配或跨语言同路径时，关系保持 `candidate`，不能冒充已审核事实。业务版和研发版知识依然通过规格、证据及审核流程生成。

- **C2KB-EXT-001**：适配器输出必须回到统一入口模型，包含稳定入口 ID、类型、动作、模块、证据和状态。
- **C2KB-EXT-002**：适配器缺失或失败时必须显式登记覆盖缺口，禁止默认为范围完整。
- **C2KB-EXT-003**：外部自动审核检查必须使用 `external.*` ID，并绑定外部报告摘要。
- **C2KB-EXT-004**：外部扩展禁止冒充参考实现内置检查。
- **C2KB-EXT-005**：项目可以增加 `sensitive_patterns`，但不得关闭私钥等基础高置信敏感信息检查。
- **C2KB-EXT-006**：第三方 Validator 或 Publisher 可以声明兼容，但必须公开其覆盖的规范编号和未实现项。
