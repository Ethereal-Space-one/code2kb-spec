# 术语与角色

## 术语

- **知识项目**：保存配置、知识源、证据和发布物的独立 Git 项目。
- **入口**：页面、按钮、自动任务、HTTP、消息、定时、命令等可触发行为。
- **事实**：带证据等级、条件、锚点和影响文件的单一结论。
- **候选包**：`prepare` 后由发布清单绑定的正文、审核依据和证据快照。
- **发布物**：业务版、研发版、版本清单和当前版本指针。

## 角色

- **Producer**：生成或维护知识项目。
- **Validator**：验证结构、证据引用、摘要和一致性记录。
- **Reviewer**：以人工授权或预授权策略审核候选包。
- **Publisher**：生成不可歧义的双版发布快照并审计。
- **Consumer**：按受众边界检索和使用发布物。

## 要求

- **C2KB-ROLE-001**：实现必须明确声明承担的角色。
- **C2KB-ROLE-002**：Producer 不得因自己生成了内容而自动获得 Reviewer 权限。
- **C2KB-ROLE-003**：策略执行身份与策略授权人必须分开记录，二者禁止相同。
- **C2KB-ROLE-004**：Consumer 必须只访问为其受众生成的发布目录。
