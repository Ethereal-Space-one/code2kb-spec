# 业务版与研发版

## 业务版

业务版面向业务用户和业务机器人，可以包含模块概览、功能范围、业务流程、规则、问答、已闭环业务意图及术语表。

## 研发版

研发版包含全部业务正文，并可增加技术实现、接口、方法、源码锚点和自动生成的事实编号对照。

## 要求

- **C2KB-VIEW-001**：两版共有业务正文必须逐字一致。
- **C2KB-VIEW-002**：业务版禁止包含源码路径、接口、类名、SQL、内部事实编号、审核队列和过程文件引用。
- **C2KB-VIEW-003**：结构化规格、待确认事项、发布清单和原始证据禁止进入任一检索目录。
- **C2KB-VIEW-004**：研发版引用的本模块事实 ID 必须能在自动生成的事实编号对照中定位。
- **C2KB-VIEW-005**：发布索引只能帮助定位正文，禁止成为某项结论的唯一承载位置。
- **C2KB-VIEW-006**：发布物内的 Markdown 链接必须能在同一受众目录内解析。
