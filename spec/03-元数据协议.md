# 元数据协议

## 通用元数据

知识 Markdown 使用单层 YAML 风格 front matter。所有值按字符串读取。

| 字段 | 要求 | 说明 |
| --- | --- | --- |
| `document_type` | 必填 | 文件名对应的固定类型 |
| `module_id` | 模块文件必填 | 稳定模块身份 |
| `review_status` | 必填 | `draft`、`reviewed` 或 `policy_reviewed` |
| `applicability` | 必填 | `current` 或 `superseded` |
| `source_revisions` | 规格和研发文件必填 | `仓库ID=固定SHA` 列表 |
| `runtime_status` | 已审核研发文件必填 | `source_only`、`runtime_verified`、`verified_deployment` |

## 配置

- **C2KB-META-001**：`知识库配置.json` 必须是 UTF-8 JSON 对象，禁止重复字段和未知顶层字段。
- **C2KB-META-002**：`standard_version` 必须为 `0.8.3`。
- **C2KB-META-003**：每个仓库必须包含唯一仓库 ID、绝对路径或完整 `${UPPER_CASE_ENV}` 引用，以及固定 Git SHA。
- **C2KB-META-004**：环境变量只能替代整个路径值；禁止 shell 展开、命令替换、默认值表达式和变量拼接。
- **C2KB-META-005**：固定提交禁止使用环境变量或分支名。
- **C2KB-META-006**：人工审核字段与策略审核字段禁止混用。
- **C2KB-META-007**：`reviewed` 必须记录审核人和日期；`policy_reviewed` 必须记录策略、授权人、执行者、证据路径及摘要。

文件名和 `document_type` 的完整对应关系以 [模板目录](../templates/) 和参考实现中的类型表为准。
