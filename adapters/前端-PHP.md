# PHP 前端取证提示

先识别实际页面入口、路由或模板、导航菜单、按钮与表单，再追 JavaScript 事件、表单提交、服务端控制器/模板逻辑、HTTP 请求以及用户可见反馈。区分 PHP 页面服务端处理与 Java 后端接口调用；不要仅凭 URL 字符串或方法名相似就认定跨仓关联。

权限显示、动态菜单、会话变量和服务端权限校验分开记录。若配置、部署路由或运行期菜单不可见，标记为未证实；不能把“代码中有页面”写成“所有用户都能看到”。

记录表单字段、提交方式、PHP 控制器/模板函数、JavaScript 调用点和 Java HTTP 接口之间的明确映射。PHP 方法可进入方法索引，但标注为前端仓库角色；页面服务器返回与 Java 接口响应不要合并成一个未经证实的契约。
