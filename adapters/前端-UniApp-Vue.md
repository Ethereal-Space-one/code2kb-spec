# UniApp / Vue 前端取证提示

先看 `src/pages.json`、路由与导航，再找页面模板中的按钮、显示/禁用条件、事件处理函数、共享 hook、API 定义与实际调用点。大纲的 `入口证据索引` 须逐条列出主包与分包的完整注册路由，类型为 `页面`；校验器会从固定提交的 `src/pages.json` 自动对账，未归类页面也不能省略。列表、详情和弹窗可能复用同一动作；同名按钮也可能去往不同页面。将页面可见条件与后端鉴权分开。

对 `uni.makePhoneCall`、平台条件编译、原生插件和外部 npm 包只描述本仓库可证实的调用与分支；外部包内部行为及其他平台结果保持未知。动态字典的代码键不等于运行期实际选项。记录每一侧固定 commit，不能由前端调用同名 API 就推断它与后端源码构成线上部署配对。

接口索引应把页面/按钮 ENT、事件处理函数、共享 hook、API 包装函数和请求参数构造逐段连起来；同名 API 在不同页面的条件可能不同。方法索引可包含关键前端 hook/函数，但必须与 Java 方法区分源码角色，不把 UI 提示写成服务端结果。
