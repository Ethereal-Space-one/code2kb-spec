# Java 后端取证提示

从实际被前端调用的路由或可证明相关的非 HTTP 入口追入 Service、状态写入、校验和异常映射。类级路由前缀、网关前缀及依赖中的常量分别取证；找不到值时保留表达式，不猜最终 URL。静态代码只能证明分支存在，不能证明运行期字典、数据库写入语义、鉴权配置或线上部署效果。

App、Admin、消息、定时及 Feign 入口按调用和用户目标归属，不因目录名称一概纳入或排除。一次请求涉及多个分支时写清适用谓词，尤其不要把某一分支的条件概括为整个功能的业务规则。

接口契约逐项记录 HTTP 方法、类级/方法级路径、参数来源（path/query/body/header）、请求与响应类型、显式校验、鉴权、异常映射和数据副作用；无证据的约束写 UNKNOWN。方法符号尽量包含类名、方法名和参数概形以区分重载。只把业务链路关键方法展开到分支和副作用；普通转发/工具方法保留一行索引即可。源码锚点取固定提交，不把同名方法或相似路由自动认作前后端已配对。
