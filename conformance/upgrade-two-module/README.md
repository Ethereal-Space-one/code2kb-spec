# 双模块源码升级案例

本案例由 Code2KB Spec 项目自行编写，供 1.0 的选择性复核与全量复核对照使用。`base/` 和 `revision-2/` 是同一公开源码仓库的两个快照；复现时按顺序将它们提交到临时 Git 仓库。两个知识模块共用该仓库的固定提交。

独立阅读源码得到的预期结论见 `expected.json`。目标提交只改变订单配送费门槛：满 80 个货币单位免配送费，旧提交为满 100 个单位。账户资料的本人查看规则及其源码未变。金额以最小货币单位传入；本案例不推断优惠、地区、线上部署或权限体系的其他规则。

预期复核范围：订单模块要重新解释业务结论；账户模块的业务语义无需重新解释，但固定提交和证据仍须按新基线核对，旧批准也不得自动沿用。若工具因全局提交约束无法安全迁移账户模块，则回退全量复核。这个案例只提供可验证的输入与预期，不能单独证明真实项目的增量收益。
