# 版本管理

Code2KB 使用三个独立版本：

| 版本 | 当前值 | 作用 |
| --- | --- | --- |
| 工程发行版本 | `0.3.0` | 文档、模板、Skill 和参考实现 |
| 知识规范版本 | `0.8.3` | 知识项目的数据与治理契约 |
| 项目 `release_id` | 由项目定义 | 某个知识库的一次内容发布 |

工程版本遵循语义化版本。规范版本发生必填字段、状态、证据或发布结构变化时必须升级。项目内容版本由各知识项目独立决定。

知识规范 `0.8.3` 是当前公开基线。工程 `0.3.0` 完整实现该规范，并新增独立一致性夹具；它不会自动改写现有知识项目。

当前公开仓库从 `v0.2.0` 开始保留可获取的发布标签。`0.1.0` 只作为变更记录中的历史版本说明，不承诺存在可获取的标签、Release 或迁移工具。版本兼容关系见[兼容性说明](compatibility.md)。
