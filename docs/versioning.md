# 版本管理

Code2KB 使用三个独立版本：

| 版本 | 当前值 | 作用 |
| --- | --- | --- |
| 工程发行版本 | `0.4.0` | 文档、模板、Skill 和参考实现 |
| 文件协议兼容标识 | `0.8.3` | 判断知识文件、清单与参考实现是否兼容；不表示使用方的项目版本 |
| 项目 `release_id` | 由项目定义 | 某个知识库的一次内容发布 |

工程版本遵循语义化版本。规范版本发生必填字段、状态、证据或发布结构变化时必须升级。项目内容版本由各知识项目独立决定。

`0.8.3` 是当前已公开文件协议的兼容标识，曾用于 0.2.x 和 0.3.x 工程。保留它是为了读取这些已公开的项目格式，不是与本地 Kit 或任何母项目联动。工程 `0.4.0` 增加可选检索扩展，不会自动改写现有知识项目。今后若重编协议号，应发布明确的格式迁移与兼容声明，不能仅更换显示数字。

当前公开仓库从 `v0.2.0` 开始保留可获取的发布标签。`0.1.0` 只作为变更记录中的历史版本说明，不承诺存在可获取的标签、Release 或迁移工具。版本兼容关系见[兼容性说明](compatibility.md)。
