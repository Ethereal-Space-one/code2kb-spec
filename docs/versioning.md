# 版本管理

Code2KB 使用三个独立版本：

| 版本 | 当前值 | 作用 |
| --- | --- | --- |
| 工程发行版本 | `0.2.0` | 文档、模板、Skill 和参考实现 |
| 知识规范版本 | `0.8.3` | 知识项目的数据与治理契约 |
| 项目 `release_id` | 由项目定义 | 某个知识库的一次内容发布 |

工程版本遵循语义化版本。规范版本发生必填字段、状态、证据或发布结构变化时必须升级。项目内容版本由各知识项目独立决定。

0.2.0 是新的公开规范基线，不提供 0.1.0 的项目迁移器。`v0.1.0` 标签和历史发布保持不变，需要读取历史项目时应使用对应标签中的工具。
