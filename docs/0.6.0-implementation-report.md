# 0.6.0 本地候选实施记录

> 状态：本地候选；尚未合并、打标签或发布 Release。工程版本 `0.6.0`，知识文件协议仍为 `0.8.3`。本记录只使用开源仓库中的夹具，不包含任何使用方知识项目。

## 已实现

- 可选本地运行账本：从功能大纲选择模块、按批次建立任务、记录实际写入和检查点；任务状态由项目文件、固定提交和 Git 复核，账本不授予批准。
- 同一知识项目的修改命令共用本地项目锁；`run-execute` 在整个确定性命令期间持锁。任务写入范围以文件摘要核对，越界时阻断并保留现场。
- `confirm-claims`、`prepare`、`approve`、`policy-review` 使用可恢复的多文件治理事务；发布替换使用持久事务，支持进程硬退出后的旧版恢复或新版审计。
- 显式 `--output json` 供 Host 调用，旧命令的默认输出和参数保持兼容；Claude Code 与 Codex 适配只渲染同一任务契约，均不持有审批状态。
- 已登记的跨模块事实引用进入影响指纹；无关系映射或影响分析失败时保守重开，不能把未知依赖判为无影响。可选检索套件只在显式发布 staging 内作为门禁。

## 已知边界

项目锁只协调同一台 Unix 主机上的受支持命令；不提供分布式锁。文件写入范围检查在任务完成时进行，不能替代 Host 权限隔离，也不能观察项目外副作用。writer 与 reviewer 的源码理解和自然语言判断仍需执行者核对；工具无法证明线上行为、业务政策或最终模型答复正确。运行账本及事务目录须保持在知识项目 Git 和发布检索范围之外。
