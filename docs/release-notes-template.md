# 发布说明审阅模板

这份模板用于检查 Code2KB Spec 的公开发版说明；正式 Release 只保留对读者有用的结论，不必照抄问题。

1. **工程版本**：本次发布的 `VERSION`、包版本、标签和 Release 标题是否一致？
2. **变更层次**：本次改变的是工具/Skill/Adapter，还是知识文件协议？只描述实际改变的层次。
3. **文件协议**：若没有改变，说明旧知识项目是否需要迁移，并链接兼容性说明；不把旧协议编号写成新增能力。若改变，列出新旧标识、读写行为、迁移方式和审计边界。
4. **使用方内容版本**：示例 `release_id` 只属于使用方项目，不能推断为 Code2KB Spec 的发行版本。
5. **公开边界**：核对 README、路线图、版本管理、兼容矩阵和 Release 草稿；清除过期“候选”状态，并检查没有本地 Kit、具体使用方、私有路径或业务资料。

本模板负责语义复核；自动检查见 `scripts/check_release_surface.py`，公开敏感内容检查见 `scripts/check_public_content.py`。
