# 兼容性说明

| 工程版本 | 知识规范 | 兼容结论 |
| --- | --- | --- |
| `0.3.x` | `0.8.3` | 当前支持；新增一致性夹具和完整元数据说明，不要求改写已符合 0.8.3 的知识项目 |
| `0.2.x` | `0.8.3` | 知识文件协议兼容；工程已停止常规维护，建议升级参考实现 |
| `0.1.0` | `0.7.0` | 只保留历史说明；当前公开历史不承诺提供该标签、Release 或自动迁移器 |

## 升级 0.2.x 到 0.3.x

1. 更新 Code2KB Spec 工程或重新安装 `code2kb`；
2. 运行单元测试和 `scripts/check_conformance.py --check-expected`；
3. 对既有知识项目运行 `code2kb check`；
4. 只有项目校验报告出现真实协议差异时才修改知识文件。

本次工程升级没有改变知识规范版本、必填元数据、审核状态机或发布目录契约。0.2.x 生成的有效 0.8.3 项目无需为了版本号重新发布。

## 兼容声明边界

第三方实现按角色和规范编号声明兼容，不使用“整体兼容”替代覆盖清单。声明格式与运行方法见[一致性说明](conformance.md)。
