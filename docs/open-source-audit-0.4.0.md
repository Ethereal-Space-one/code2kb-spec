- 工程版本 `0.4.0`，知识规范仍为 `0.8.3`。默认发布继续生成业务版、研发版和 registry 2.0；检索扩展须显式启用。

- 公开检索夹具只含合成的订单与账号案例，不含实际客户知识库、机器人配置、凭据或源码快照。

## 仍需验证

- 公开合成规模测试通过唯一标记制造清晰区分，只验证处理规模与确定性，不代表真实检索难度。尚无经过许可的脱敏规模库基线；固定夹具采用逐用例全通过门禁，尚未据真实查询分布设定统计阈值。
- 对本机一份较大的既有发布物做只读副本试跑时，基础发布指针含知识规范 `0.8.3` 未定义的 `history_backend` 字段，原 `audit-release` 先行拒绝；因此未得到该库的检索规模或质量结论，也未修改原库。本版不会为该私有扩展放宽公开的基础发布审计。
- `lexical-v1` 只提供可重复的离线词法基线。生产向量检索、生成回答和机器人接入效果没有验证。
- compact 模式的主题与未知边界比较是文本级检查；人工仍需复核事实语义和业务措辞。
- Skill 分层只验证了静态结构、链接和默认上下文大小；尚无相同任务的 Agent 输出合规率对照，不能据字节减少推断质量提升。
- Python 3.9–3.13 的跨版本结果须以 CI 实际运行记录为准；本地结果只覆盖当前解释器。
- 受本机网络限制，干净虚拟环境无法从 PyPI 下载构建依赖；本地安装验证使用系统已有依赖，不能替代 CI 的全新环境安装检查。

这些边界不影响本版作为离线检索实验扩展使用，但不构成任何生产知识库的准确性、权限安全或问答质量认证。
