# 模块取证

每轮围绕一个模块，从用户入口追调用、服务方法、字段写入与读取、错误分支和可见范围。记录稳定事实、接口、方法 ID，固定提交锚点及消费文件；无法证实的运行结果进入未知边界。

高影响字段须追到已发现的生产与消费路径。需要业务目的时加载 [业务意图扩展](../extensions/business-intent.md)。规格结构按模板；细节见 [模块取证与规格](../references/模块取证与规格.md)。

读取源码正文时按配置中的仓库路径与固定提交使用 Git 对象命令；见上述取证手顺。不要用当前工作树内容配旧提交行号。`evidence-snapshot` 可复核锚点与片段摘要，但不代替阅读源码正文。

准备新发布包前，按本模块大纲入口逐项填写规格的 `## 大纲覆盖核对` 表：已取证关联事实，待核查或范围外写原因；无接口的入口也不能省略。
