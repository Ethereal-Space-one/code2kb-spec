# 核心契约

- 工程版本、知识规范版本和内容 `release_id` 独立记录。源码只读取项目配置钉定的 Git 提交，证据锚点使用仓库 ID、仓库相对路径和行号；不以未提交工作区代替。
- 区分源码可证行为、静态推断、业务确认、运行观测和未知。配置键已知不等于运行取值已知；界面隐藏不等于服务端授权；未找到调用方不等于功能废弃。
- 每条会改变问答的结论保留条件、例外、失败和未知边界。业务正文使用业务语言，研发正文保留实现与证据。没有运行证据时不宣称线上已验证。
- 源码仓库只读取证。未经用户授权不发布、不连接机器人、不推送远端。人工审核和预授权策略审核分别记身份，不能让工具冒充审核人。
- 只有当前任务要求的扩展才载入。必要的文件和字段以 `SPEC.md`、模板及校验器为准。
