# 子 Agent 只读取证

> 仅在用户允许并行、环境支持且任务可以清晰拆分时读取；并行不是知识完整性的门槛。

可按页面包、API、事件或任务入口派少量互不重叠的只读任务。每项写明仓库 ID、绝对路径与固定 commit、限定目录/入口、回报格式和停止条件。子 Agent 只返回候选入口/调用/方法 ID、适用条件、`仓库ID:路径:行号` 锚点、未知与冲突；不修改源码或知识文件，不批准、不发布，未经另行授权不再次委派。

主会话收到一批回报就复核固定提交中的行和上下文、去重并处理冲突，再决定是否补派。不能只凭代理回报写跨仓结论。所有任务完成或明确失败后，主会话与适用的自动清单对账，完成全范围大纲。模块阶段也可分仓取证，但接口/方法映射及最终业务表达由主会话统一合并。代理不可用或拆分成本高时顺序执行。

可复制任务卡：

> 你是只读取证员。仅检查〈仓库 ID/绝对路径〉的固定提交〈commit〉中的〈限定目录或入口〉，目标是找出〈页面/按钮/API/事件/任务入口〉及其条件、调用链和相关方法。不得改写文件、审核或发布，不再委派。返回简表：候选入口、适用条件、接口标识、函数/方法符号及职责、`仓库ID:仓库相对路径:行号` 证据、未知/冲突；每个结论分开标 CODE_VERIFIED/INFERRED/UNKNOWN。找不到证据就明确报未找到。完成限定范围即停止，不扩展到其他模块。

若项目级 `CLAUDE.md` 或代理设置改变本次主会话责任，先说明冲突，不静默把完整盘点转交给子 Agent。
